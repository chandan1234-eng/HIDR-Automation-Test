# HIDR Nepal – Manual Testing Documentation

## Project Overview

This folder contains manual testing documentation for the HIDR Nepal website.

**Website URL:** https://hidr.com.np/

The purpose of this documentation is to verify the website's functionality, user interface, navigation, forms, and responsiveness through manual testing.

## Documentation Included

**HIDR_NEPAL_MANUAL_TESTING.xlsx**

The Excel workbook contains:

- Test Scenarios
- Test Cases
- Preconditions
- Test Steps
- Expected Results
- Actual Results
- Test Execution Status

## Testing Scope

Manual testing covers different pages and components of the HIDR Nepal website, including:

- Home Page
- About Us
- What We Offer
- Our Team
- Careers
- Partner With Us
- Publications
- Reports
- Policy Briefs
- Annual Reports
- Books
- Blog
- Gallery
- Contact Us

## Testing Activities

- Functional Testing
- UI Testing
- Navigation Testing
- Form Validation Testing
- Responsive Testing
- Test Execution and Result Reporting
